Project Snapshot

The Village @ Pasir Panjang, a 148-unit development across 9 blocks built in 2016, faced critical intercom failures. Obsolete legacy panels had compromised daily access, particularly in blocks with selective private lift access, creating significant daily friction for residents.

What This Project Represents

A transition from system breakdown to a fully restored living experience. This project moved beyond simple hardware replacement to deliver estate-wide consistency and predictable daily convenience.

The Challenge

A Legacy System Failing the Estate Rhythm

The existing system had become unreliable, outdated, or no longer fit for purpose. The Samsung intercom system had become partially non-functional, creating a growing gap between the development's premium architecture and its daily operational reality.

The lack of mobile access meant that residents were tethered to legacy physical handsets, while fragmented systems led to inconsistent security logs and significant audit gaps.

Critical Human Impact: Several blocks had non-functional visitor panels, especially those with private lift access. Residents were forced to physically come down to bring visitors up—creating daily inconvenience, frustration, and security concerns.

The system was no longer aligned with how users expected to live or operate. A simple replacement of individual failing parts would not solve the broader issue.

Transformation

From System Breakdown to Seamless Access

The transition from a failing legacy environment to a modernised infrastructure resolved the estate's most persistent access frustrations.

AFTER

Decision Point

A Strategic Choice for the Council

The management faced a critical decision: continue patching a failing system — or redesign how the system should function.

With multiple panels failing and the system no longer supported, patch repairs were no longer viable. The management faced a critical decision: continue managing breakdowns—or fully upgrade to a modern, reliable system.

The issue was no longer technical—it was operational and affecting daily living.

Approach

Why This Approach Was Chosen

A condominium upgrade requires a balance between modern functionality and practical implementation. Our strategy for The Village focused on three core pillars of decision logic:

  • •

    Infrastructure Preservation: We designed the system to work with existing cabling wherever possible, avoiding the cost and disruption of a full structural rebuild.

  • •

    Estate-Wide Consistency: The solution ensured a uniform user experience across all 9 blocks, eliminating the fragmented "patchwork" performance of the previous system.

  • •

    Scalable Architecture: By selecting a modern IP-based system, we provided a foundation that can easily accommodate future security upgrades and platform expansions.

The Solution

Three Layers Supporting Everyday Access

The upgrade focus on access for visitors and residents for the premises, tightening access for the private lifts for 5 blocks, and vehicle access control for visitors and residents.

Layer 01

Intercom System

  • 21 x Akuvox R28A deployed
  • Installed across all blocks
  • New access Cards issued
  • Smartplus Apps issued for residents

Learn more about Akuvox →

Layer 02

Lift Integration

  • 5 blocks with private lift access
  • 5 units of Akuvox EC32 deployed
  • Access for private or common lobby enabled
Layer 03

Vehicle Access

  • Implemented GantryGo
  • Added 2 LPR Cameras
  • Digitalised Visitor Management
  • Replaced barrier system
