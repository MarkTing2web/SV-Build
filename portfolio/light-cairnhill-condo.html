Project Snapshot

Securevision has been supporting Light at Cairnhill since 2015. When the building's standalone access and intercom systems reached technical obsolescence in 2024, we resolved the inherent friction by transforming fragmented silos into a single coordinated system.

Client / MCST MCST 2928 Light@Cairnhill

Sector Residential / Condominium
Project Type Intercom, Access & Lift Integration

Scope 27 Entry Points / 8 Lifts
Technologies Implemented
Akuvox Integrated intercom and access control ecosystem. Hikvision HD surveillance network maintained since 2015.
The Challenge

Fragmented Systems and Aging Infrastructure

Before the 2024 upgrade, Light@Cairnhill operated across multiple, entirely independent security layers, creating significant operational friction for both guards and residents.

System Silos Before Transformation

  • Standalone intercom system with zero software integration.
  • Access control managed by an independent third-party vendor.
  • Ageing hardware leading to increasing failures and high maintenance costs.
Transformation

From Fragmentation to Unification

Feature Before (Fragmented) After (Consolidated)
Operational Control Multiple disconnected logins Single Unified Dashboard
Vertical Access Standalone Lift Controllers Integrated Intercom/Lift Link
Resident Credentials Legacy Cards / Biometrics Mobile Keys / Face / MiFare
Data Visibility Manual log reconciliation Automated Real-time Audit
Decision Point

Redesigning the Access Architecture

Replacing only the intercom would have preserved the estate's fragmentation. Securevision decided to consolidate both intercom and access simultaneously. This was not simply a system replacement—it was a restructuring of how access is managed across the development, ensuring the system worked as one under unified control.

Our Approach

Consolidated Vertical Security

Our approach centered on the Akuvox platform to integrate visitor and resident access. By synchronising the visitor entry system with the lift controllers and door access, the new architecture ensures that visitors proceed only to authorised floors, with an automated log for every entry event.

The Solution

Unified Estate Infrastructure

1. Integrated Intercom & Access

Consolidated visitor calling and resident authentication into a single Akuvox-based lobby portal.

2. Lift Control Integration

Full integration of vertical movement permissions tied directly to entry credentials, improving isolation.

3. Mobile Resident Keys

App-based controls for residents to manage visitor calls and self-access from any location.

4. Perimeter Surveillance

Maintaining the legacy Hikvision network as a dedicated high-reliability visual layer.

Results & Impact

Measurable Operational Improvement

✓ Eliminated Fragmented Workflows

Restored single-point control for the managing agent via a unified, transparent dashboard.

✓ Reduced Administrative Overhead

Consolidating access layers has significantly reduced the complexity of estate credential management.

✓ Restored Predictability

Residents no longer second-guess access points; the entry experience is consistent across all 27 points.
