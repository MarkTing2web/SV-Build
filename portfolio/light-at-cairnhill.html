Light@Cairnhill

Consolidating Fragmented Access Infrastructure into an Integrated Multi-Point System

27 Entry Points Integrated
8 Lifts Synchronised
2 Core Operational Systems
10yr Site Support History

Project Overview
Client MCST 2928 Light@Cairnhill
Location Cairnhill Circle, Singapore
Sector Residential
Project Type System Consolidation & Upgrade
Completion August 2024 - January 2025

Securevision has maintained a long-term supporting role at Light@Cairnhill since 2015, initially managing the site’s surveillance infrastructure. While the CCTV layer has been steadily upgraded—including major expansions in 2016 and 2021—the building’s broader access systems remained fragmented across multiple vendors and legacy platforms.

In 2024, as legacy hardware reached technical obsolescence, the MCST initiated a major project to move away from vendor-siloed operations and consolidate the ageing intercom and fingerprint access layers into a more integrated, future-ready architecture.

Condominium Solutions Explore access strategies for high-density residential estates. Access Systems See the integrated hardware architecture used for professional entry control.
What This Project Represents

System Simplification: Transitioning from siloed legacy hardware to an integrated interface, reducing vendor dependency and operational friction.

The Challenge

Overcoming Fragmented System Silos

Prior to the 2024 upgrade, Light@Cairnhill operated three entirely independent security systems: Securevision’s CCTV surveillance, a separate vendor’s fingerprint access, and a third vendor’s traditional intercom. This fragmentation created significant operational hurdles.

High Vendor Complexity

Managing three separate maintenance contracts and service levels slowed response times and increased administrative overhead for the managing agent.

Zero Software Integration

Guard operations required toggling between multiple interfaces to verify visitor identity and grant entry, creating delays at peak hours and reducing situational awareness.

Hardware Obsolescence

Both the intercom and fingerprint systems reached end-of-life status simultaneously, leaving the site vulnerable to component failure without available replacements.

Our Approach

Consolidation Over Hardware Replacement

Akuvox X915 integrates visitor and resident access, rendering antiquated fingerprint readers obsolete.

Instead of a standard like-for-like hardware replacement, Securevision designed a strategy to consolidate the access and intercom layers. The goal was to bring these two critical functions under a single software ecosystem while maintaining a stable bridge to the existing CCTV surveillance.

System Strategy

Securevision proposed an Akuvox-based solution that integrated intercom, access control, and lift control into a single interface. By choosing this integrated solution, we could unify visitor communication and resident authentication into a single management portal, significantly reducing the complexity of the estate's security stack.

Technical Integration

The solution involved unifying 27 lobby entrance panels and 8 private lift controllers into a single software dashboard for the on-site security team. While CCTV remains a dedicated secondary system, the high-frequency tasks of resident and visitor management are now fully integrated.

Systems Used

Consolidated Deployment Architecture

The 2024 upgrade was built on an IP-native backbone, designed to bridge previously separate operational functions.

Core Layer

Intercom & Access (Akuvox)

Unified the visitor call system with resident face/card authentication across all lobbies and perimeter gates into one interface.

Security Layer

Lift Integration (Akuvox)

Direct synchronisation of authenticated entry with vertical movement using Akuvox-based lift controller architecture.

User Interface

Mobile Access (Akuvox SmartPlus)

App-based resident access and a dedicated guard station console, reducing management to two core software interfaces.

Measured Outcomes

Operational Efficiency & Resilience

The successful consolidation has delivered immediate improvements in estate management and system reliability.

Integrated

Guards manage 27 intercom panels and the full access database from a single software environment.

Simplified

Reduced management overhead by centralising intercom and access maintenance under one partner.

Resilient

Replaced at-risk legacy hardware with an IP architecture, eliminating technical obsolescence risks.

Why This Matters to Similar Sites

This project proves that consolidation is often more valuable than a 'full' platform migration. By focusing on integrating the highest-friction systems first, the estate gained immediate efficiency without the cost of a total infrastructure overhaul.
