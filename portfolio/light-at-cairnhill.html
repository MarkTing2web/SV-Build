CONDOMINIUM CASE STUDY 📍 Cairnhill, Singapore

Resolving Daily Friction from Fragmented Access Systems

When intercom, access, and visitor systems don’t work together, everyday entry becomes unpredictable—for both residents and guards. At Light@Cairnhill, we resolved this friction by transforming fragmented silos into a single coordinated system.

Project Context

Existing Relationship / Trust Positioning:
Securevision has been supporting the development since 2015, maintaining the existing CCTV system and carrying out strategic upgrades over the years. This established history provided critical familiarity with the site’s terrain and its operational needs when the building's standalone access and intercom systems reached technical obsolescence in 2024.

This situation is common in developments where different systems were implemented over time, each functioning on its own, but not designed to work together.

The Challenge

Fragmented Systems and Aging Infrastructure

Before the 2024 upgrade, Light@Cairnhill operated across multiple, entirely independent security layers, creating significant operational friction for both guards and residents.

System Silos Before Transformation:

  • Surveillance: CCTV system maintained by Securevision since 2015.
  • Communication: Standalone traditional intercom system with zero software integration.
  • Access Control: Biometric fingerprint readers managed by an independent third-party vendor.

Critical Operational Friction: Guards had to rely on multiple systems with limited visibility, while residents experienced inconsistent access experience depending on the entry point—turning daily entry into an unpredictable and frustrating experience.

Primary Pain Points:

  • Fragmented Workflows: Guards were constantly switching between systems, leading to a lack of visibility and confusion in tracking visitors.
  • Infrastructure Risk: Ageing hardware across disconnected systems resulted in increasing failures and high maintenance costs.
  • Resident Dissatisfaction: Inconsistent access performance created daily hurdles for owners and guests alike.
Securevision's Approach

Redesigning the Access Architecture

Akuvox X915 integrates visitor and resident access, rendering antiquated fingerprint readers obsolete.

The original plan was to upgrade the intercom first and defer the biometric reader system to a later phase. However, replacing only one system would have preserved the fragmentation, leaving the estate with the risks of staying fragmented and guards managing disconnected workflows.

Securevision decided to consolidate both simultaneously. This was not simply a system replacement—it was a restructuring of how access is managed across the development, ensuring the system worked as one under unified control.

This was not simply a system replacement—it was a restructuring of how access is managed across the development.

This design-led approach was delivered through an Akuvox-based solution that integrates intercom functionality, people access control, and lift coordination into a single, cohesive software interface.

Consolidated Vertical Security

By synchronising the visitor entry system with the lift controllers and door access, the new architecture ensures that visitors can only proceed to the authorized floor, and there is a automatic log of who authorised, allowing for audit should there be a security concern.

Solution Delivered

From Multiple Systems to a More Consolidated Structure

The upgrade moved the development from three separate security layers into a more professional, consolidated structure. This transition focused on the high-friction interaction points while maintaining the existing, reliable CCTV surveillance as a dedicated layer.

Function 01

Integrated Intercom & Access

Consolidated visitor calling and resident authentication (Face/Mobile/PIN) into a single, reliable lobby portal.

Function 02

Lift Control Integration

Full integration of vertical movement permissions tied directly to the entry credential, improving secure floor isolation.

Function 03

Mobile resident keys

App-based controls for residents to manage visitor calls and self-access from any location.

Results & Impact

Measurable Operational Improvement

The transformation at Light@Cairnhill prioritised decision-maker clarity and long-term maintainability for the managing agent and MCST.

Eliminated fragmented workflows

Restored single-point operational control for the managing agent, who now manages every entry point via a unified, transparent dashboard.

Restored single-point control

Removed the dependency on disconnected systems by consolidating all access layers. This coordination significantly reduced administrative complexity.

Removed system dependency

Resolved resident hurdles by removing dependency on ageing biometric readers and introducing secure, mobile-based access that works predictably every time.

The Felt Impact

The success of the Cairnhill consolidation is the restoration of predictability. Residents no longer need to second-guess access points, and guards operate with a clearer, more predictable workflow—ensuring a smoother, friction-free daily experience from the main entrance to individual lobby arrival.

Strategic Conclusion

This project demonstrates how a condominium can decisively resolve system silos. By choosing consolidation over a phased approach, the MCST achieved immediate situational control and reduced long-term maintenance overhead. It was a strategic decision that improved maintainability and removed the operational debt of multiple, ageing security layers.
