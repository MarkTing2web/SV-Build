CONDOMINIUM CASE STUDY 📍 Cairnhill, Singapore

From Fragmented Systems to a More Integrated Access Experience

Upgrading intercom and access at Light@Cairnhill to improve control, simplify operations, and modernise resident access.

Property Type Condominium

Scope Intercom + Access + Lift Integration

Existing Relationship / Trust Positioning:
Securevision has been supporting the development since 2015, maintaining the existing CCTV system and carrying out strategic upgrades over the years. This established history provided critical familiarity with the site’s terrain and its operational needs when the building's standalone access and intercom systems reached technical obsolescence in 2024.

Discovery Paths
Condominium Solutions Explore integrated access strategies for residential high-rise estates. Access Operations See the software and hardware used for professional gate and lobby control.
The Challenge

Fragmented Systems and Aging Infrastructure

Before the 2024 upgrade, Light@Cairnhill operated across multiple, entirely independent security layers, creating significant operational friction for both guards and residents.

System Silos Before Transformation:

  • Surveillance: CCTV system maintained by Securevision since 2015.
  • Communication: Standalone traditional intercom system with zero software integration.
  • Access Control: Biometric fingerprint readers managed by an independent third-party vendor.

Primary Pain Points:

  • Operational Friction: No single interface for managing access and visitors; guards had to manually handle disparate systems from different vendors.
  • Infrastructure Risk: Ageing and obsolete intercom hardware resulted in increasing failures and limited spare-part availability.
  • Disconnected Workflows: Zero coordination between lobby access control and vertical lift movement.
  • Limited Convenience: No mobile-based access for residents, Issue of high-maintenance for biometric fingerprint readers.
Securevision's Approach

Redesigning the Access Architecture

Akuvox X915 integrates visitor and resident access, rendering antiquated fingerprint readers obsolete.

Rather than replacing components individually, Securevision approached the project as a solution architect. We redesigned the development's access architecture to reduce vendor fragmentation and improve overall administrative control.

This design-led approach was delivered through an Akuvox-based solution that integrates intercom functionality, people access control, and lift coordination into a single, cohesive software interface.

Consolidated Vertical Security

By synchronising the visitor entry system with the lift controllers, the new architecture ensures that visitors can only proceed to the authorized floor, removing the need for manual guard intervention or separate lift-card overrides.

Solution Delivered

From Multiple Systems to a More Consolidated Structure

The upgrade moved the development from three separate security layers into a more professional, consolidated structure. This transition focused on the high-friction interaction points while maintaining the existing, reliable CCTV surveillance as a dedicated layer.

Function 01

Integrated Intercom & Access

Consolidated visitor calling and resident authentication (Face/Mobile/PIN) into a single, reliable lobby portal.

Function 02

Lift Control Integration

Full integration of vertical movement permissions tied directly to the entry credential, improving secure floor isolation.

Function 03

Mobile resident keys

App-based controls for residents to manage visitor calls and self-access from any location.

Results & Impact

Measurable Operational Improvement

The transformation at Light@Cairnhill prioritised decision-maker clarity and long-term maintainability for the managing agent and MCST.

Clean Operations

Simplified workflows for the guard team, who now manage all entry points from a single management dashboard.

Consolidated

Reduced system fragmentation by moving the estate from three independent vendors down to two primary systems.

App-Enabled

Immediate improvement in resident experience through the adoption of secure, mobile-based access methods.

Strategic Conclusion

This project demonstrates how a condominium can transition from siloed legacy hardware to a modern, consolidated architecture without undergoing a total, site-wide infrastructure overhaul. By focusing on integrating the highest-friction systems first, the development gained immediate situational control and reduced long-term maintenance overhead.
