The Challenge

A Telephony System That Left Internal Security Unaddressed

The Bale had a telephony-based intercom covering only the main gate. Visitors at the gate could ring residents via a phone line — but there was no visual verification, no lobby access control, and no staircase security. Internal common areas were effectively unsecured beyond the gate itself.

The CCTV system had aged beyond its useful life. Camera coverage was patchy, image quality had degraded, and the existing setup gave the management committee limited confidence in the footage it was capturing. With only 36 units across 2 blocks, the estate needed a lean but complete solution — one that secured all entry layers without overbuilding.

The project required replacing the telephony intercom, adding lobby and staircase access control that hadn't existed before, and installing a fresh CCTV system — all without disrupting residents during the changeover.

The Solution

Securing Every Layer — Gate, Lobby, Staircase, and Surveillance

A phased replacement that added security at entry points that previously had none, while restoring full CCTV coverage across the estate.

A. Main Gate

Video Intercom Replacing Telephony

The existing telephony-based intercom at the main gate was replaced with an Akuvox S532 video intercom. Residents can now see and speak to visitors before granting access — from the indoor monitor or from the mobile app when away from home.

B. Block Lobbies

New Access Layer for Both Blocks

Three Akuvox S532 units were installed across the lobbies of both blocks — a layer of access control that had not existed before. Visitors entering a block must now be admitted by a resident, closing a gap the original system left entirely open.

C. Staircases

Resident-Only Staircase Access

Four Akuvox A02S card readers were installed at staircase doors across both blocks. Staircases are now restricted to residents using their access cards — visitors are directed through the main gate and lobby only, with no staircase bypass.

D. CCTV

15-Camera IP Surveillance with NVR

The ageing CCTV system was replaced in full. Fifteen IP cameras were installed across the estate — covering the main gate approach, lobbies, carpark, common corridors, and key external areas — all recording to a centralised NVR.

Results & Impact

A Complete Security Layer Where None Existed Before

✓ Visual Verification at Every Entry

Residents can see and verify every visitor at the main gate and each block lobby before granting access — replacing a system that gave no visual feedback at all.

✓ Staircases Secured for the First Time

Card-controlled staircase doors mean only residents can move freely between floors. Visitors remain channelled through the lobby — a security layer the estate never had before.

✓ Reliable Surveillance Restored

Fifteen new IP cameras replaced an ageing system with degraded coverage. The management committee now has clear, reliable footage across all common areas and entry points.

Securevision Insight

"Small condominiums often carry the same security gaps as large ones — just with less budget to fix them. At The Bale, the original system covered only the main gate and left both lobbies and staircases completely open. The right approach isn't to downgrade the solution — it's to right-size it. Two blocks, 36 units, four access points: designed precisely, nothing wasted."
