How to Use These Guides

Start With Your System, Not Your Budget

🔍

Specifying a New System

Start with the guide for your primary system — CCTV or access control for most properties. Read the Design Standard section before requesting quotations.

🔧

Upgrading an Existing System

Go to the Investment Guide or Maintenance section at the end of each guide. These sections flag when an upgrade is genuinely needed versus when servicing will do.

🏗️

Planning a Renovation

Read the Security Planning During Renovation guide before your M&E schedule is finalised — then use the individual system guides to specify each system.
